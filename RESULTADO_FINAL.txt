═══════════════════════════════════════════════════════════════════════════════
📱 COMO FUNCIONA O APP
═══════════════════════════════════════════════════════════════════════════════

1. INICIALIZAÇÃO:
   Usuário abre app → Cordova inicia → Solicita permissão GPS

2. LOCALIZAÇÃO INICIAL:
   App obtém primeira posição → Centra mapa → Mostra status

3. RASTREAMENTO:
   Usuário clica "Iniciar" → watchPosition começa → A cada mudança:
   a) Calcula distância do ponto anterior
   b) Adiciona ao total
   c) Atualiza cards na tela
   d) Redesenha rota no mapa
   e) Incrementa cronômetro

4. PARADA:
   Usuário clica "Parar" → clearWatch para GPS → UI congela

5. RESET:
   Usuário clica "Resetar" → Limpa todos os dados → Volta ao início
