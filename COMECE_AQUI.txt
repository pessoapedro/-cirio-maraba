🚀 COMECE EM 3 PASSOS
================================================================================

PASSO 1: Instale as ferramentas (uma única vez)
   • Node.js: https://nodejs.org
   • Java JDK: https://www.oracle.com/java/technologies
   • Android Studio: https://developer.android.com/studio

   Tempo: 1-2 horas (maior parte é download)

PASSO 2: Configure o ambiente
   • Abra GUIA_COMPLETO.md
   • Siga ETAPA 1 - Preparação do Ambiente
   • Execute os comandos PowerShell

   Tempo: 30-60 minutos

PASSO 3: Compile e teste
   cd c:\apps\cirio
   npm install
   cordova plugin add cordova-plugin-geolocation
   cordova build android
   cordova run android

   Tempo: 5-10 minutos (primeira vez mais longa)

⚡ COMANDOS PRINCIPAIS
================================================================================

Primeiros comandos:
  npm install                                ← Instala dependências
  cordova plugin add cordova-plugin-geolocation ← Adiciona GPS

Compilação:
  cordova build android --debug              ← Debug (testes)
  cordova run android                        ← Compila e roda

Testes:
  adb devices                                ← Lista celulares
  adb logcat                                 ← Ver logs

Produção:
  cordova build android --release            ← Release (publicação)

✨ CARACTERÍSTICAS DO APP
✨
================================================================================

✓ Mapa em Tempo Real
  - Desenha rota conforme você se move
  - Atualiza a cada 5 segundos
  - Compatible com OpenStreetMap + Leaflet

✓ GPS de Alta Precisão
  - Usa Haversine para calcular distância
  - Atualiza continuamente
  - Funciona em 2G/3G/4G/WiFi

✓ 4 Cards Informativos
  - Distância Total (5 km - configurável)
  - Distância Percorrida (em tempo real)
  - Distância Restante (diminui com movimento)
  - Tempo Decorrido (HH:MM:SS)

✓ Interface Moderna
  - Gradiente roxo/magenta no topo
  - Cards coloridos (azul, verde, laranja)
  - Responsivo (celular + tablet)
  - Animações suaves

✓ Fácil de Usar
  - 3 botões principais: Iniciar, Parar, Info
  - Sem complicações
  - Ideal para qualquer pessoa
